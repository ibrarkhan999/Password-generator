## 🎨 How It Works

| Step | Action |
|:----:|--------|
| 1️⃣ | Set your desired password **length** |
| 2️⃣ | Toggle **uppercase**, **lowercase**, **numbers**, and **symbols** |
| 3️⃣ | Tap **Generate** to create a password |
| 4️⃣ | Tap **Copy** to send it straight to your clipboard |

## 🚀 Getting Started

### Prerequisites

| Requirement | Version |
|:--|:--|
| Node.js | `>= 18` |
| Yarn / npm | latest |
| Android SDK | latest |

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/PasswordGenerator.git

# Navigate to project
cd PasswordGenerator

# Install dependencies
yarn install

# Run on Android
yarn android
```

<br>

> 🛡️ No backend, no network calls, no data collection.
